# МедиаСуздаль — угадай цену за ночь 🍷

Продолжение «МедиаКоми», но теперь про посуточную аренду в Суздале и в миллениальском
дофаминовом стиле (необрутализм: толстые обводки, сочные цвета, жёсткие тени).

## Концепция
Смотри фото квартиры с Avito → двигай бегунок → угадай цену **за ночь** (не за квартиру целиком).
Диапазон цен: 2 000–15 000 ₽/ночь. В раунде 10 лотов из 20 подготовленных, максимум 100 баллов.

## Что отличается от «МедиаКоми»
- **Данные**: 64 объявления посуточной аренды Суздаля (из `суздаль.xlsx`), отобрано 20 с полным
  набором фото; в `data.js` — цена за ночь, рейтинг, отзывы, адрес, бейджи («Суперхозяин» и т.п.).
- **Дизайн**: dopamine / neobrutalism — сиреневый фон, жёлто-красно-синие акценты, чёрные рамки,
  offset-тени, наклонённые плашки, декоративные фигурки.
- **Копирайт**: миллениальские мемы — adulting, котики, винишко, кофе, «Друзья», зумеры.
- **Мемы на экране ответа**: помимо эмодзи — рисованные SVG-мемы по точности догадки:
  🎯 Doge («much точность»), 😂 удивлённый Пикачу, 🙂 This is fine, 😬 Сердитый котик,
  😭 плачущий котик, 💀 «RIP бюджет».
- **Персоны финала**: «Вечный торгаш» / «Московский инвестор» / «Суперхозяин интуиции».

## Файлы
- `index.html` — вся игра (HTML+CSS+JS, без зависимостей).
- `data.js` — `window.LISTINGS`: 20 объявлений.
- `img/` — фото квартир (превью Avito 208×208, как в предыдущей игре).

## Запуск
```bash
cd suzdal-game && python3 -m http.server 8642
# http://localhost:8642
```
Открывать через локальный сервер (иначе браузер не подгрузит `data.js` с file://).
